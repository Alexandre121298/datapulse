# DataPulse

Application fullstack de suivi météo développée avec Java 21, Spring Boot, React et PostgreSQL.

## Application en ligne

**[Accéder à DataPulse](https://datapulse-api-722245064686.europe-west1.run.app/)**

Créez un compte ou connectez-vous pour ajouter des villes à votre espace personnel et consulter leurs conditions météorologiques.

## Organisation du dépôt

- [`datapulseAPI`](./datapulseAPI) : API REST Spring Boot.
- [`datapulsewebapp`](./datapulsewebapp) : interface React et TypeScript.
